  1. 01

    Minecraftを起動する

    当サーバーは Java Edition・Bedrock Edition どちらでも 参加できます。 PC・スマホ・Switch・コンソール等、お持ちのデバイスで遊べます。

    Java Edition Bedrock (PC) Bedrock (Switch) Bedrock (iOS / Android) Bedrock (PS / Xbox)
  2. 02

    サーバーアドレスを追加する

    接続に必要なアドレスはこちら。ボタンでコピーできます。

    daikonsv.f5.si
    ポート番号は Java Edition：25565 / Bedrock Edition：19132（各デフォルト値）です。
  3. 03

    Java Edition から参加する場合

    タイトル画面から マルチプレイ => サーバーを追加 を選択し、アドレスを入力してください。

    • サーバーアドレスに daikonsv.f5.si を入力
    • 「完了」を押してリストから接続
    JAVA EDITION
  4. 04

    Bedrock Edition から参加する場合

    タイトル画面から プレイ => 発見 => 外部サーバーを追加を選択し、アドレスを入力してください。

    • サーバーアドレスに daikonsv.f5.si を入力
    • ポートは 19132
    • 「保存して参加」を押す

    以下のボタンから直接追加することもできます。

    サーバーを追加する サーバー一覧を開く
    BEDROCK EDITION
  5. 05

    ルールを守って楽しむ

    接続前に必ずサーバールールをお読みください。 グリーフ・チート・荒らし行為は対処の対象となります。 ルールを守って、みんなで楽しいサーバーにしましょう！
